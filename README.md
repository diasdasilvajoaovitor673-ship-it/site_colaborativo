# Workshop de Versionamento — Projeto Colaborativo

## Descrição

Este projeto foi desenvolvido como parte do workshop de versionamento ministrado pelo professor Emmerson Santa Rita da Silva. O objetivo da atividade é aplicar, na prática, conceitos de controle de versão utilizando Git e GitHub em um ambiente colaborativo de desenvolvimento.

O projeto consiste na criação de um site institucional simples, dividido em quatro seções principais:

- Cabeçalho da página;
- Seção de cursos;
- Seção "Sobre";
- Rodapé.

Além disso, foi criada uma feature específica para melhoria do estilo visual utilizando CSS.

---

## Organização das Branches

O repositório foi estruturado utilizando branches específicas para cada funcionalidade do projeto.

### Branch principal

- `main`
  - Responsável por consolidar as funcionalidades finalizadas do projeto.

### Features

- `feat/cabecalho`
  - Desenvolvimento do cabeçalho da página.

- `feat/cursos`
  - Implementação da seção de cursos.

- `feat/sobre`
  - Desenvolvimento da seção "Sobre".

- `feat/rodape`
  - Implementação do rodapé da aplicação.

- `feat/melhorar-estilo-css`
  - Responsável pela estilização visual utilizando CSS.

### Documentação

- `docs/readme`
  - Branch destinada à documentação do projeto.

---

## Objetivos do Workshop

Durante o desenvolvimento do projeto, foram praticados conceitos importantes relacionados a versionamento e colaboração, como:

- Criação e gerenciamento de branches;
- Uso de commits;
- Integração de funcionalidades;
- Organização colaborativa do código;
- Utilização do GitHub como plataforma de hospedagem e colaboração.
